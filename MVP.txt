====================================================
MVP GOAL
====================================================

Build the smallest functional version of Pathfinder AI that answers:

"Where should I go right now?"

A user should be able to:
1. Complete their profile/preferences.
2. Share or enter their location.
3. Specify budget and available time.
4. Select interests.
5. Get personalized nearby place recommendations.
6. View recommendations on a map.
7. Generate a simple itinerary.
8. Save/bookmark places.

The MVP should prioritize FUNCTIONALITY over advanced AI.

4. PERSONALIZED RECOMMENDATION ENGINE

DO NOT start with complex machine learning.

Create a deterministic recommendation scoring service.

Calculate a recommendation score using factors such as:

- Interest/category match: 35%
- Distance: 20%
- Budget compatibility: 20%
- Available time compatibility: 15%
- Opening/availability: 10%

The weights should be configurable.

Example logic:

recommendation_score =
    interest_score * 0.35 +
    distance_score * 0.20 +
    budget_score * 0.20 +
    time_score * 0.15 +
    availability_score * 0.10

The engine should:

1. Fetch relevant nearby places.
2. Filter out unsuitable places.
3. Score each place.
4. Sort places by score.
5. Return the top recommendations.

Each recommendation should include an explanation, for example:

"Recommended because you enjoy nature, it is within your budget, and only 15 minutes away."

Create this as a reusable backend service, not controller/view logic.
